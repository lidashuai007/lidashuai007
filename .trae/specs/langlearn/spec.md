# LangLearn - 多语种在线教育平台 - Product Requirements Document

## Overview
- **Summary**: 一款支持英语、日语、韩语等主流语言的沉浸式在线语言学习平台，提供分级课程、互动练习、进度追踪、个性化推荐、社区交流与成就激励等完整学习闭环。
- **Purpose**: 帮助用户通过系统化、互动化、游戏化的方式高效掌握多门外语。
- **Target Users**: 语言学习者（初学者到进阶者），希望通过结构化课程和互动练习提升语言能力的人群。

## Goals
- 提供覆盖英语、日语、韩语的分级课程体系（A1-C2 / N5-N1 / TOPIK 1-6）
- 构建四大互动学习模块：单词记忆、语法练习、口语跟读、听力训练
- 完整记录并可视化用户学习进度
- 支持用户注册、登录、个人资料管理
- 基于学习数据的个性化学习路径推荐
- 社区交流功能（发帖、评论）与成就激励系统（徽章、积分、排行榜）

## Non-Goals
- 不实现真实后端服务器（使用浏览器 localStorage 模拟数据持久化）
- 不实现真实语音识别（使用 Web Speech Synthesis API 做 TTS 朗读，跟读评分基于录音完成度模拟）
- 不实现实时聊天/即时通讯（社区为异步发帖评论模式）
- 不实现支付/订阅系统
- 不实现管理员后台内容管理（课程内容内置预设）

## Background & Context
- 项目为从零开始的全新前端应用
- 采用纯前端单页应用架构（HTML5 + CSS3 + 原生 JavaScript），无需构建步骤，直接浏览器打开即可运行
- 使用浏览器原生 Web Speech API 实现语音朗读，覆盖多语种发音
- 使用 localStorage 实现数据持久化，模拟用户体系与学习记录

## Functional Requirements

### 用户体系
- **FR-1**: 用户可通过邮箱+密码注册账号，注册信息保存至 localStorage
- **FR-2**: 用户可通过邮箱+密码登录，登录状态持久化
- **FR-3**: 用户可退出登录，切换账号
- **FR-4**: 用户可查看和编辑个人资料（昵称、目标语言、当前等级）

### 分级课程体系
- **FR-5**: 提供英语、日语、韩语三门语言课程
- **FR-6**: 每门语言按等级分级（英语 A1-C2，日语 N5-N1，韩语 TOPIK 1-6）
- **FR-7**: 每个等级包含多个单元/课程，每课有明确的学习目标
- **FR-8**: 课程内容包含词汇、语法、例句等学习材料

### 互动学习模块
- **FR-9**: 单词记忆模块 — 闪卡模式展示单词，支持翻面查看释义、发音、标记掌握程度
- **FR-10**: 语法练习模块 — 选择题/填空题形式，即时反馈对错与解析
- **FR-11**: 口语跟读模块 — 展示句子，TTS 朗读示范，用户点击录音跟读，播放回放
- **FR-12**: 听力训练模块 — 播放音频，用户根据听力内容选择正确答案

### 学习进度追踪
- **FR-13**: 记录每个课程/模块的完成状态和得分
- **FR-14**: 展示学习统计（总学习时长、完成课程数、掌握单词数、连续学习天数）
- **FR-15**: 可视化进度仪表盘（环形进度图、柱状图等）

### 个性化学习路径
- **FR-16**: 基于用户当前等级、学习历史、薄弱环节推荐下一步学习内容
- **FR-17**: 首页展示"为你推荐"课程卡片
- **FR-18**: 根据正确率动态调整推荐难度

### 社区交流
- **FR-19**: 用户可发布动态/帖子（文字内容）
- **FR-20**: 用户可对帖子点赞、评论
- **FR-21**: 社区帖子按时间倒序展示

### 成就激励系统
- **FR-22**: 基于学习行为授予徽章（首课完成、连续7天、掌握100词等）
- **FR-23**: 积分系统 — 完成学习任务获得积分
- **FR-24**: 排行榜 — 按积分排名展示用户

## Non-Functional Requirements
- **NFR-1**: 平台响应式设计，适配桌面与移动端
- **NFR-2**: 页面加载时间 < 2 秒（本地资源）
- **NFR-3**: 界面支持中文显示，语言学习内容保持原语言
- **NFR-4**: 所有交互有即时视觉反馈
- **NFR-5**: 代码结构清晰，模块化组织

## Constraints
- **Technical**: 纯前端实现，无后端服务；使用 localStorage 持久化；使用 Web Speech API 做语音合成
- **Business**: 课程内容为预设示例数据，覆盖各语言基础等级
- **Dependencies**: 浏览器支持 localStorage、Web Speech Synthesis API、MediaRecorder API

## Assumptions
- 用户使用现代浏览器（Chrome/Edge/Firefox 最新版）
- 用户设备有麦克风（口语跟读功能需要）
- 浏览器支持所需的 Web API

## Acceptance Criteria

### AC-1: 用户注册与登录
- **Type**: `rule`
- **Given**: 新用户访问平台
- **When**: 用户填写邮箱、密码、昵称并点击注册
- **Then**: 账号创建成功并自动登录，可进入主界面
- **Pass Condition**: 注册后用户数据出现在 localStorage，刷新页面后保持登录状态
- **Evidence**: 打开页面注册新账号，刷新后仍为登录状态

### AC-2: 用户登录与登出
- **Type**: `rule`
- **Given**: 已注册用户
- **When**: 输入正确邮箱密码登录，或点击登出
- **Then**: 成功登录进入主页，或登出后回到登录页
- **Pass Condition**: 登录成功跳转主页；登出后清除登录态
- **Evidence**: 登录/登出流程正常，localStorage 登录态正确变化

### AC-3: 分级课程展示
- **Type**: `rule`
- **Given**: 登录用户进入课程页
- **When**: 选择语言（英/日/韩）
- **Then**: 展示该语言的等级列表，每个等级下有对应课程
- **Pass Condition**: 三门语言均有分级课程，等级划分符合标准
- **Evidence**: 英语 A1-C2、日语 N5-N1、韩语 TOPIK 1-6 课程均可访问

### AC-4: 单词记忆模块
- **Type**: `rule`
- **Given**: 用户进入某课的单词记忆
- **When**: 浏览闪卡，翻面查看释义，点击发音
- **Then**: 可切换单词正反面，播放单词发音，标记掌握程度
- **Pass Condition**: 闪卡翻面动画正常，TTS 发音正常，掌握状态保存
- **Evidence**: 单词卡可翻面、可发音、掌握状态持久化

### AC-5: 语法练习模块
- **Type**: `rule`
- **Given**: 用户进入语法练习
- **When**: 作答选择题/填空题
- **Then**: 即时显示对错，给出解析，记录得分
- **Pass Condition**: 答题后立即反馈，得分保存到进度
- **Evidence**: 答题反馈正确，得分持久化

### AC-6: 口语跟读模块
- **Type**: `rule`
- **Given**: 用户进入口语练习
- **When**: 点击播放示范音频，点击录音跟读，播放回放
- **Then**: 示范音频播放正常，录音可回放
- **Pass Condition**: TTS 示范朗读正常，录音功能可用且可回放
- **Evidence**: 示范发音播放，录音回放有声音

### AC-7: 听力训练模块
- **Type**: `rule`
- **Given**: 用户进入听力训练
- **When**: 播放听力音频并选择答案
- **Then**: 播放正常，作答后反馈对错
- **Pass Condition**: 音频播放正常，答案判定正确
- **Evidence**: 听力音频播放，作答反馈正确

### AC-8: 学习进度追踪
- **Type**: `rule`
- **Given**: 用户完成若干学习任务
- **When**: 进入进度/统计页面
- **Then**: 展示已完成课程数、掌握单词数、连续学习天数、总积分
- **Pass Condition**: 统计数据随学习行为更新并持久化
- **Evidence**: 完成任务后统计数字增加，刷新后保持

### AC-9: 进度可视化
- **Type**: `rubric`
- **Dimension**: 进度数据可视化质量
- **Scale**: 1-5
- **Anchors**: 1 = 纯文字数字；3 = 简单进度条；5 = 环形图+柱状图+日历热力图等多维度可视化
- **Pass Threshold**: >= 4
- **Evidence**: 进度页包含至少两种图表类型

### AC-10: 个性化推荐
- **Type**: `rule`
- **Given**: 用户有学习历史
- **When**: 进入首页
- **Then**: 展示基于学习数据推荐的课程卡片
- **Pass Condition**: 推荐内容与用户等级/进度相关，非随机
- **Evidence**: 首页推荐区有内容，且与用户进度匹配

### AC-11: 社区发帖
- **Type**: `rule`
- **Given**: 登录用户
- **When**: 发布帖子
- **Then**: 帖子出现在社区列表，包含作者、时间、内容
- **Pass Condition**: 帖子成功保存并展示，刷新后仍在
- **Evidence**: 发帖后列表更新，刷新后帖子仍存在

### AC-12: 社区互动
- **Type**: `rule`
- **Given**: 社区存在帖子
- **When**: 点赞或评论
- **Then**: 点赞数增加，评论显示在帖子下
- **Pass Condition**: 点赞和评论数据持久化
- **Evidence**: 点赞/评论后刷新仍保留

### AC-13: 成就徽章
- **Type**: `rule`
- **Given**: 用户完成特定学习行为
- **When**: 达到徽章条件（如完成首课、连续学习7天）
- **Then**: 自动授予对应徽章，在个人页展示
- **Pass Condition**: 徽章解锁条件触发后徽章点亮
- **Evidence**: 完成首课后"初学乍练"徽章解锁

### AC-14: 积分与排行榜
- **Type**: `rule`
- **Given**: 用户完成学习任务获得积分
- **When**: 进入排行榜页
- **Then**: 按积分降序展示用户排名
- **Pass Condition**: 排行榜数据正确，当前用户高亮
- **Evidence**: 排行榜按积分排序，当前用户位置高亮

### AC-15: 响应式设计
- **Type**: `rubric`
- **Dimension**: 多端适配表现
- **Scale**: 1-5
- **Anchors**: 1 = 仅桌面可用；3 = 桌面+移动基本可用但有错位；5 = 桌面/平板/手机均完美适配
- **Pass Threshold**: >= 4
- **Evidence**: 在不同视口宽度下界面正常

### AC-16: 整体交互体验
- **Type**: `rubric`
- **Dimension**: 用户交互流畅度与视觉反馈
- **Scale**: 1-5
- **Anchors**: 1 = 无反馈卡顿；3 = 基本反馈；5 = 动画流畅、反馈即时、沉浸感强
- **Pass Threshold**: >= 4
- **Evidence**: 页面切换、答题反馈、弹窗等有流畅过渡动画
